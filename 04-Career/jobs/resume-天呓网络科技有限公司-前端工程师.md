# 概述

**天呓网络科技有限公司 · 前端工程师**（2026.05 - 至今，约，请核实起始月）— 独立设计开发「数据上报助手」Chrome MV3 插件，作为核心成员参与「天呓 ERP · 广告资产与运营协同管理平台」（React 19 + TypeScript + Redux Toolkit / RTK Query）开发，并参与跨境电商 Shopify 主题「Shrine Theme Pro」的二次开发。

# 核心职责

- 独立设计开发数据上报助手 Chrome MV3 插件，逆向解析 Meta Ads Manager 虚拟滚动表格 DOM 结构叠加真实订单数据
- 主导将约 4700 行单体 `content.js` 重构为 WXT + Vue 3 + TypeScript 模块化工程
- 独立搭建广告账户、FB 个号、像素管理、IP 登记四大资产模块，主导存量遗留系统 TS 化迁移
- 基于 Shopify 官方 Dawn 主题扩展购物车转化 App Block（倒计时/阶梯进度条/条件赠品/追加销售）与商品 3D/AR 展示、多语言/RTL 支持

# 核心成果

- 约 4 周内产出 144 次提交，净变更约 +37,500/-20,300 行代码；资产统计报表页并发请求数降至 1/3
- 数据上报助手订单接口请求量从 N 次/页降至 ⌈N/80⌉ 次/页
- Shrine Theme Pro：全仓 446 个文件覆盖 18 类页面模板，购物车转化 App Block 达 7 个，国际化覆盖 26 种语言
