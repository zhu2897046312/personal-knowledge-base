# 概述

**深圳市启创生活科技有限公司 · 电商运营 & 自动化开发**（2025.06 - 2025.11）— 跨境电商公司电商运营 + 自动化开发双线并行，用脚本开发与工具链优化显著提升团队效率。

# 核心职责

- 开发 Python/Golang 自动化脚本，实现速卖通库存/财务报表自动抓取入库、Excel 订单自动拆分与批量打印
- 使用 Photoshop/剪映独立完成产品主图设计与产品展示视频制作
- 负责 OZON 平台从 0 到 1 完整流程搭建

# 核心成果

- 2 套核心自动化脚本累计为运营团队每月节省 80+ 小时人工操作时间，错误率降低 >90%
- OZON 平台 3 天内实现首单，后续稳定维持日出 20 单
