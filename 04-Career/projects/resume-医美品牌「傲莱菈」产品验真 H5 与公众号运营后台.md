# 概述

**医美品牌「傲莱菈」产品验真 H5 与公众号运营后台**（广东真格软件有限公司实习期间参与）— 面向医美机构的产品验真业务，消费者扫码/输入序列号完成产品验真与质保卡查询，配合微信公众号使用；拆分为 H5 客户端与运营后台两个独立前端工程，共用同一套后端接口。技术栈：Vue 3 · TypeScript · Vite · Vant 3 · Ant Design Vue 4 · Pinia

# 核心贡献

- 开发移动端验真 H5：扫码 + 手动输入双路径查询，接入条码识别库与微信 JS-SDK 适配公众号场景
- 设计机构端/用户端双动线（登录鉴权、质保卡录入与查询、图片凭证上传等）
- 落地运营后台 RBAC（部门/角色/管理员/权限/数据字典）与序列号/机构/质保卡三类主数据管理，支持 Excel 批量导入

# 核心成果

- 独立交付 **2** 个前端工程（H5 + 运营后台），共用同一套后端接口
- H5 覆盖首页验真、机构端、用户端 **3** 大功能域；运营后台 RBAC 覆盖 **5** 类基础配置
