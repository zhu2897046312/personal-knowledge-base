# 概述

**跨境电商 Shopify 主题「Shrine Theme Pro」**（2026.08 - 至今 · 天呓网络科技工作项目，核心成员）— 基于 Shopify 官方 Dawn 主题二次开发的跨境独立站主题，强化购物车侧转化能力与商品详情展示体验，覆盖 26 种语言与 RTL 布局。技术栈：Shopify Liquid · Online Store 2.0 · 原生 Web Components（JS）· CSS

# 核心贡献

- 基于 Dawn 参考主题扩展 7 个购物车侧转化 App Block（倒计时锁单、阶梯满减/包邮进度条、条件赠品、购物车内追加销售等），条件规则引擎最多支持 6 种触发方式
- 落地捆绑套装促销、定价方案对比表、品牌故事时间轴等营销型 Section，及 3 个独立站营销落地页模板
- 集成商品 3D/AR 模型查看、图片放大镜、快速加购弹窗、分面筛选与搜索建议等标准电商体验组件
- 搭建 26 种语言的国际化资源与 RTL 布局开关，覆盖礼品卡兑换页与完整客户账户体系模板

# 核心成果

- 全仓覆盖 **18** 类页面模板、**446** 个文件（`blocks` 98 / `sections` 91 / `snippets` 131）
- 购物车侧自定义转化 App Block 达 **7** 个，条件规则引擎最多支持 **6** 种触发方式
- 国际化覆盖 **26** 种语言（52 个 locale/schema 文件），内建 RTL 布局能力
