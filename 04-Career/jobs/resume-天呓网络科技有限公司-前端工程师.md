# 概述

**天呓网络科技有限公司 · 前端工程师**（2026.05 - 至今，约，请核实起始月）— 独立设计开发「数据上报助手」Chrome MV3 插件，作为核心成员参与「天呓 ERP · 广告资产与运营协同管理平台」（React 19 + TypeScript + Redux Toolkit / RTK Query）开发并独立承接其中 Snapchat 广告投放前端模块，独立设计开发自研广告投放后端服务「svr_ads」的 Snapchat 渠道后端（Go + Gin + GORM + Redis + asynq），参与跨境电商 Shopify 主题「Shrine Theme Pro」的二次开发，并主导开发 Python + FastAPI 后端服务「SaaS 店铺商品采集系统」。

# 核心职责

- 独立设计开发数据上报助手 Chrome MV3 插件，逆向解析 Meta Ads Manager 虚拟滚动表格 DOM 结构叠加真实订单数据
- 主导将约 4700 行单体 `content.js` 重构为 WXT + Vue 3 + TypeScript 模块化工程
- 独立搭建广告账户、FB 个号、像素管理、IP 登记四大资产模块，主导存量遗留系统 TS 化迁移
- 独立设计实现 Snapchat 广告渠道前端（账号管理/广告发布/模板管理）与后端服务「svr_ads」的 Snapchat 渠道模块，实现该渠道前后端全栈交付
- 基于 Shopify 官方 Dawn 主题扩展购物车转化 App Block（倒计时/阶梯进度条/条件赠品/追加销售）与商品 3D/AR 展示、多语言/RTL 支持
- 主导设计 Python + FastAPI 后端服务「SaaS 店铺商品采集系统」，覆盖 12+ 平台自动识别采集、反爬与代理池、字段口径治理

# 核心成果

- 约 4 周内产出 144 次提交，净变更约 +37,500/-20,300 行代码；资产统计报表页并发请求数降至 1/3
- 数据上报助手订单接口请求量从 N 次/页降至 ⌈N/80⌉ 次/页
- Snapchat 全栈模块：后端 3 周 72 次提交（+53,093/-3,980 行），前端 2 周 90 次提交（+20,755/-4,627 行）
- Shrine Theme Pro：全仓 446 个文件覆盖 18 类页面模板，购物车转化 App Block 达 7 个，国际化覆盖 26 种语言
- SaaS 店铺商品采集系统：约 1 个月 86 次提交，落地 12 个平台适配器 + 通用兜底解析，38 个测试文件覆盖核心链路
