# 概述

**电商数据自动化系统**（2025.07 - 2025.11 · 个人独立设计与开发）— 基于 Selenium 打通速卖通、菜鸟、店小秘等多平台库存/出入库流水/销量数据的自动化采集与 MySQL 入库全链路。技术栈：Python · Selenium · pandas · SQLAlchemy · MySQL

# 核心贡献

- 用 Selenium 驱动 Chrome 自动登录并导出速卖通（POP/全托）、菜鸟、店小秘等平台 5+ 类报表，封装通用下载完成检测与文件归档逻辑
- 设计货品 ID 分组批量采集方案（5 个/组）与跨 iframe 递归元素查找，解决菜鸟在途库存明细页大批量查询的性能与定位难题
- 统一菜鸟与店小秘两种异构出入库流水数据源，通过字段映射与业务类型映射字典归一化入库同一张表
- 独立开发可循环合并的 Excel 表格工具，字符串化读写避免长数字精度丢失，并配套中文使用手册供非技术人员使用

# 核心成果

- 历时约 4 个月完成 **80 次**迭代提交，覆盖 **4+** 电商/物流平台的采集入库全链路
- 支撑近千个货品 ID 的在途库存明细自动化批量采集
- 统一 **2 种**异构数据源入库，消除人工分别整理的重复工作
- Excel 合并工具支持增量循环合并，配套手册使非技术同事可独立使用
