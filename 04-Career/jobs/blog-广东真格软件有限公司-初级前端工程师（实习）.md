# 概述

**广东真格软件有限公司 · 初级前端工程师（实习）**（2025.03 - 2025.06）

以 Java 方向面试进入公司，入职后快速转向前端开发，实习期内作为项目核心成员交付 3 个商业项目的前端开发。

# 背景

以 Java 方向面试进入公司，后快速转向前端开发。入职第一个月内通过自学 + AI 工具深度辅助，快速掌握 Vue 3（Composition API）+ Nuxt 3（SSR）以及 HTML5、CSS3、JavaScript（ES6+），迅速完成角色切换并承担实际开发任务。

# 主要工作内容与成果

作为项目核心成员，参与跨境珠宝电商平台、海外充电宝租赁平台、广州医美人贸易平台等 3 个商业项目的前端开发，覆盖 PC 端、移动端 H5 及后台管理系统。

**核心技术与实践：**

- 基于 Nuxt.js 负责电商主站 PC 与移动端响应式界面开发与核心交互逻辑，利用服务端渲染（SSR）显著提升首屏加载速度与 SEO 效果
- 使用 Naive UI + Tailwind CSS 构建高复用组件库，保障多端设计语言一致性与开发效率
- 独立使用 Vue 3 + Element Plus / Ant Design Vue 完成电商 ERP 后台部分模块开发（商品、订单、用户管理等）
- 快速适配微信环境，独立完成医美平台 H5 质保卡绑定页面全流程开发及机构管理后台功能（详见 [[blog-医美品牌「傲莱菈」产品验真 H5 与公众号运营后台]]）

**AI 辅助开发亮点：** 自 2022 年开始深度使用 AI 工具，本次实习中将 DeepSeek、ChatGPT、Cursor 深度融入日常开发流程——用 Cursor 做代码补全与重构，用 DeepSeek + ChatGPT 辅助技术方案调研、问题定位（Nuxt SSR 样式 FOUC、设备指纹同构等难点）、性能优化方案设计与文档编写。

# 量化成果

- 交付 3 个商业项目的前端开发，覆盖 PC 端、移动端 H5、后台管理系统三种形态
- 入职 1 个月内完成从 Java 方向到 Vue3/Nuxt3 前端开发的角色切换

# 技术与能力提升

完成了从后端开发思维到现代前端工程化思维的转变，积累了真实商业项目全栈交付经验（C 端 + B 端），为后续独立负责复杂项目（如 [[blog-基于 Gin 与 Nuxt 的跨境电商独立站]]）奠定了基础。
