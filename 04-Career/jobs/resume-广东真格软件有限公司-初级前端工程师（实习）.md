# 概述

**广东真格软件有限公司 · 初级前端工程师（实习）**（2025.03 - 2025.06）— 入职一个月内自学掌握 Vue 3（Composition API）+ Nuxt 3（SSR），完成从 Java 方向到前端开发的角色转变。

# 核心职责

- 作为项目核心成员参与跨境珠宝电商平台、海外充电宝租赁平台、广州医美人贸易平台等 3 个商业项目的前端开发，覆盖 PC 端、移动端 H5 及后台管理系统
- 基于 Nuxt.js 负责电商主站 SSR 开发，使用 Naive UI + Tailwind CSS 构建高复用组件库
- 独立使用 Vue 3 + Element Plus / Ant Design Vue 完成电商 ERP 后台部分模块开发
- 快速适配微信环境，独立完成医美平台 H5 质保卡绑定页面全流程开发及机构管理后台功能

# 核心成果

- 入职 1 个月内完成角色切换并承担实际开发任务
- 积累真实商业项目全栈交付经验（C 端 + B 端），为后续独立负责复杂项目奠定基础
