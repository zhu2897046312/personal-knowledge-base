# 概述

**天呓网络科技有限公司 · 前端工程师**（2026.05 - 至今，约，请核实起始月）

三线并行：独立设计开发 Chrome MV3 插件「数据上报助手」，作为核心成员参与「天呓 ERP」企业级中后台系统开发，同时参与跨境电商 Shopify 主题「Shrine Theme Pro」的二次开发。

# 背景

源笔记（`D:\workspace\blog`）中这段任职经历本身未单独撰写背景段落，本文内容整理自关联项目 [[blog-数据上报助手-ChromeMV3插件]]、[[blog-天呓ERP-广告资产与运营协同管理平台]]、[[blog-跨境电商 Shopify 主题「Shrine Theme Pro」]] 与已有简历文档的交叉记录；任职起始月标注为约数，对外使用前需本人核实准确日期。

# 主要工作内容与成果

**数据上报助手（Chrome MV3 插件）**（详见 [[blog-数据上报助手-ChromeMV3插件]]）：

- 逆向解析 Meta Ads Manager 虚拟滚动表格 DOM 结构，实现无官方接口下的数据精准叠加，开发隐身脚本拦截平台反插件检测弹窗
- 设计批量订单接口与并行请求架构，将逐行 GET 重构为分片并行 POST，构建 5 级时区降级解析链路实现跨时区账户日期自动对齐
- 主导将约 4700 行单体 `content.js` 重构为 WXT + Vue 3 + TypeScript 模块化工程（9 个职责域、40+ 模块）

**天呓 ERP · 广告资产与运营协同管理平台**（React 19 + TypeScript + Redux Toolkit / RTK Query，详见 [[blog-天呓ERP-广告资产与运营协同管理平台]]）：

- 独立搭建广告账户、FB 个号、像素管理、IP 登记四大资产模块
- 主导存量遗留系统从无类型 JSX 迁移为 TypeScript + RTK Query 架构，统一接入新网关并修复多个历史遗留 bug
- 落地运营团队在线状态协同机制（上线/下线/请假），抽取跨页面复用组件消除重复实现
- 发现并合并跨业务域重复定义的查询 endpoint，主导仓库编码规范治理（禁三目、禁 enum、组件职责拆分）

**跨境电商 Shopify 主题「Shrine Theme Pro」**（基于 Dawn 二次开发，详见 [[blog-跨境电商 Shopify 主题「Shrine Theme Pro」]]）：

- 扩展 7 个购物车侧转化 App Block（倒计时锁单、阶梯满减/包邮进度条、条件赠品、购物车内追加销售等），条件规则引擎最多支持 6 种触发方式
- 落地捆绑套装促销、定价方案对比表、品牌故事时间轴等营销型 Section，及独立站营销落地页模板系列
- 搭建 26 种语言的国际化资源与 RTL 布局开关，覆盖礼品卡兑换页与完整客户账户体系模板

# 量化成果

- 数据上报助手：订单接口请求量从 N 次/页降至 ⌈N/80⌉ 次/页，存量代码从约 4700 行单文件重构为 9 目录、40+ 模块
- 天呓 ERP：约 4 周内产出 144 个非合并提交，净变更约 +37,500 / -20,300 行代码；资产统计报表页并发请求数从 3 次降至 1 次
- Shrine Theme Pro：全仓 446 个文件覆盖 18 类页面模板，购物车转化 App Block 达 7 个，国际化覆盖 26 种语言

# 技术与能力提升

在没有官方扩展接口的强约束下走通"可行性验证（油猴脚本）→ 正式交付（MV3 插件）→ 架构重构"全生命周期；在真实企业级中后台项目中实践了新模块从 0 到 1 搭建、存量系统迁移、跨模块性能治理与规范化重构的全链路工作；在 Shopify Dawn 官方架构之上二次开发，积累了在不破坏上游可维护性前提下扩展自定义功能、并将营销运营诉求抽象为可配置规则引擎的产品化思维。
