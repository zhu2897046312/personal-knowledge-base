# Personal Knowledge Base

Obsidian / Markdown 个人知识库。活动笔记按目录归类；旧稿在 `08-Archive/`。

## 目录

| 目录 | 用途 |
|------|------|
| `00-Inbox/` | 临时记录，稍后整理 |
| `01-Projects/` | 进行中的项目笔记 |
| `02-Learning/` | 学习笔记、概念与实践 |
| `03-Engineering/` | 开发规范、踩坑与工程速查 |
| `04-Career/` | 面试、简历、求职 |
| `05-Life/` | 生活 |
| `06-AI/` | AI 相关 |
| `07-Templates/` | 笔记模板 |
| `08-Archive/` | 迁移前旧文件归档 |
| `assets/` | 图片等附件 |

## 模板

复制 `07-Templates/` 下对应模板新建笔记：

- `tmpl-pitfall.md` — 踩坑（问题 / 原因 / 解决方案 / 验证）
- `tmpl-cheatsheet.md` — 速查（概述 / 要点 / 用法）
- `tmpl-learning.md` — 学习（目标 / 知识点 / 示例 / 总结）

相关链接使用 `[[笔记名]]`。
