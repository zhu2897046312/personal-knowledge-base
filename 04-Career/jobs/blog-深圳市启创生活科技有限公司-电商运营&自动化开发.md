# 概述

**深圳市启创生活科技有限公司 · 电商运营 & 自动化开发**（2025.06 - 2025.11）

在跨境电商公司负责电商运营工作，同时承担自动化开发任务，用脚本开发与工具链优化显著提升团队运营效率。

# 背景

在跨境电商公司负责电商运营工作，同时承担自动化开发任务。通过脚本开发与工具链优化，显著提升团队运营效率，体现了较强的工程化思维和业务落地能力。

# 主要工作内容与成果

**自动化脚本开发（Python + Golang）**

- 开发 Python 自动化脚本，每日从速卖通平台自动抓取库存数据与财务报表，并完成数据清洗后一键导入公司数据库，将原手动操作 1.5 小时缩短至 5 分钟（详见 [[blog-电商数据自动化系统-多平台库存采集与入库]]）
- 编写 Golang 脚本，实现 Excel 订单按备货单号自动拆分、根据指定模板生成打印文件，并调用打印机一键批量打印，将原手动处理 2 小时缩短至 5 分钟

**电商内容生产与平台运营**

- 使用 Photoshop 独立设计并优化 150+ 款公司产品主图，提升产品页面专业度与视觉吸引力
- 利用剪映及专业相机拍摄、制作 20+ 个高质量产品展示视频，用于电商平台推广和社交媒体运营
- 负责 OZON 平台从 0 到 1 完整流程搭建，3 天内实现首单，后续稳定维持日出 20 单的稳定出单量

# 量化成果

- 完成 2 套核心自动化脚本，累计为运营团队每月节省 80+ 小时人工操作时间
- 批量打印与数据处理自动化后，人为操作错误率降低 >90%，显著提升出货效率与准确率
- 通过产品主图与视频内容优化，提升店铺点击率与转化率，间接推动销量增长

# 技术与能力提升

深入使用 Python、Golang 进行业务自动化开发，结合 AI 工具（DeepSeek、ChatGPT、Cursor）辅助代码生成、调试与方案设计，进一步提升了跨语言快速学习和工程落地能力。同时将前端开发中积累的工程化思维应用到运营场景，实现「技术驱动业务效率提升」的闭环实践。
