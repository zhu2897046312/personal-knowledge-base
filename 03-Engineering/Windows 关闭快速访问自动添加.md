# 概述

关闭快速访问的自动填充后，列表只保留手动固定的文件/文件夹。

# 要点

取消勾选并清除：

- 显示最近使用的文件
- 显示常用文件夹
- （如果有）显示 Office.com 文件

# 用法

```text
Win + E
  → 右上角「···」
  → 选项
  → 隐私（Privacy）
  → 取消所有勾选
  → 点击【清除（Clear）】
  → 应用 → 确定
```
